# Architecture Documentation

This directory explains system scope, component responsibilities, data and event flows, reliability guarantees, local-to-AWS portability, delivery phases, and deferred decisions.

The primary document is [architecture.md](architecture.md). Keep diagrams close to the narrative they support and update both when service boundaries or data ownership change. Proposed elements must be labeled as such; measured throughput, latency, recovery, and cost results belong in evidence documents rather than unsupported architecture claims.
