# Collector repair and implementation guide

This document explains the implemented collector, exact file locations, and why each
piece exists. It is written for someone new to Python services, WebSockets, Kafka,
and event-driven systems. The examples reflect the code currently present in the
repository; explanatory comments are more extensive here than in production files.

## 1. What was wrong and what is now implemented

The original collector was not runnable because `config.py`, `exchange_client.py`,
`producer.py`, and `main.py` were empty. Its event model also had these problems,
which the implementation in this guide now addresses:

- It generates a random event ID. Receiving the same exchange trade twice will create two IDs, so downstream replay and deduplication will not work.
- It accepts empty exchange and symbol values.
- It accepts timestamps without a timezone even though the architecture requires UTC.
- It silently accepts misspelled or unexpected envelope fields.
- Its payload can contain Python objects that cannot be serialized as JSON.
- It omits fields required by the architecture, including source sequence and tracing fields.
- The event contract exists only as Python code instead of in the repository's canonical `schemas/` directory.
- There is no executable package entry point, dependency lockfile, or implementation test suite.

The most important rule is this: **the same exchange trade must always produce the same `event_id`, even after a disconnect, restart, or replay.**

Why split it this way:

- `apps/collector/` owns the runnable process and its lifecycle.
- `packages/exchange_adapters/` owns exchange-specific API details.
- `schemas/` is the language-neutral source of truth for event shapes.
- `tests/` proves that these pieces continue to agree.
- The `src/` layout prevents Python from accidentally importing files merely because the current directory happens to contain them.

### File: `/packages/exchange_adapters/src/crypto_exchange_adapters/models.py`

Create:

```python
# `dataclass` generates an initializer and useful comparison/representation methods.
from dataclasses import dataclass
# Exchange timestamps are represented as timezone-aware datetime objects.
from datetime import datetime
# Raw exchange JSON has a provider-controlled shape, so this boundary uses `Any`.
from typing import Any


# `frozen=True` makes instances immutable after construction.
@dataclass(frozen=True)
class ExchangeTrade:
    """One trade extracted from an exchange WebSocket message."""

    # Canonical lowercase provider name, such as `coinbase`.
    exchange: str
    # Provider instrument name, such as `BTC-USD`.
    symbol: str
    # Immutable provider trade ID used to build a stable event ID.
    source_event_id: str
    # Provider message sequence used for ordering/gap detection; some feeds omit it.
    source_sequence: int | None
    # The time the exchange says the trade happened, not local receipt time.
    event_time: datetime
    # Parsed source trade retained for audit, debugging, and replay.
    raw_payload: dict[str, Any]
```

Explanation:

- This object is the boundary between an exchange and the collector.
- `source_event_id` is the exchange's immutable trade ID and drives stable identity.
- `source_sequence` is message-order metadata used for future gap detection. It is
  deliberately separate because one Coinbase message can contain several trades.
- `event_time` is when the trade happened at the exchange.
- `raw_payload` preserves the parsed source trade for later investigation.
- `frozen=True` prevents accidental mutation after the object is created.

Do not import `MarketTradeRawEvent` here. A reusable package must not import code from an application that consumes it.

## 5. Implement one concrete exchange adapter

The following is a Coinbase Advanced Trade public-feed example. If you select another exchange, keep the same `ExchangeTrade` output but replace the subscription and parsing logic with that exchange's documented fields.

### File: `/packages/exchange_adapters/src/crypto_exchange_adapters/coinbase.py`

Create:

```python
# The collector uses asyncio so one thread can wait efficiently for network data.
import asyncio
# WebSocket frames are JSON text and must be decoded into Python values.
import json
# Logging records connection state and malformed input without using `print()`.
import logging
# Random jitter stops many service instances from reconnecting simultaneously.
import random
# `AsyncIterator` describes a stream whose next item is awaited.
from collections.abc import AsyncIterator
# Coinbase timestamps are converted into Python datetime values.
from datetime import datetime
# The exact shape of external JSON is not controlled by this repository.
from typing import Any

# `connect` opens and manages the asynchronous WebSocket connection.
from websockets.asyncio.client import connect
# This exception represents normal and abnormal WebSocket disconnections.
from websockets.exceptions import ConnectionClosed

# All exchange adapters produce the same small, exchange-neutral object.
from .models import ExchangeTrade

# A module-level logger automatically includes this module's import path in messages.
LOGGER = logging.getLogger(__name__)


class CoinbasePublicTradeClient:
    """Reads public trades and converts them to exchange-neutral objects."""

    def __init__(
        self,
        websocket_url: str,
        symbols: list[str],
        reconnect_initial_seconds: float,
        reconnect_max_seconds: float,
    ) -> None:
        # Store configuration once so `trades()` does not repeatedly read settings.
        self._websocket_url = websocket_url
        self._symbols = symbols
        self._reconnect_initial_seconds = reconnect_initial_seconds
        self._reconnect_max_seconds = reconnect_max_seconds

    async def trades(self) -> AsyncIterator[ExchangeTrade]:
        """Keep connecting and yield normalized trades until cancelled."""

        # Start with a short retry delay. Successful connections reset this value.
        delay = self._reconnect_initial_seconds

        # This service is intended to run continuously; cancellation exits the loop.
        while True:
            try:
                # The context manager closes the socket when this block exits.
                async with connect(
                    self._websocket_url,
                    # Pings identify dead connections that otherwise appear open.
                    ping_interval=20,
                    ping_timeout=20,
                    close_timeout=10,
                ) as websocket:
                    # Ask Coinbase to send trade updates for only the desired products.
                    await websocket.send(
                        json.dumps(
                            {
                                "type": "subscribe",
                                "product_ids": self._symbols,
                                "channel": "market_trades",
                            }
                        )
                    )

                    # Coinbase recommends a heartbeat subscription because a quiet
                    # channel may otherwise close after 60-90 seconds without updates.
                    await websocket.send(
                        json.dumps(
                            {
                                "type": "subscribe",
                                "channel": "heartbeats",
                            }
                        )
                    )

                    LOGGER.info(
                        "Connected to Coinbase public WebSocket for %s",
                        ",".join(self._symbols),
                    )
                    # A successful connection proves the exchange is reachable again.
                    delay = self._reconnect_initial_seconds

                    # Each loop iteration waits for the next complete WebSocket frame.
                    async for raw_message in websocket:
                        try:
                            # Convert JSON text into dictionaries and lists.
                            message = json.loads(raw_message)
                            # Reject a valid JSON primitive/array because the feed contract
                            # says each top-level message must be a JSON object.
                            if not isinstance(message, dict):
                                raise TypeError("WebSocket message must be a JSON object")

                            # One Coinbase frame may contain more than one trade.
                            for trade in self.parse_message(message):
                                # `yield` sends one item to the collector without ending the stream.
                                yield trade
                        except (KeyError, TypeError, ValueError, json.JSONDecodeError):
                            # One bad frame should not terminate an otherwise healthy connection.
                            LOGGER.exception("Ignoring malformed Coinbase message")

            except asyncio.CancelledError:
                # Cancellation means the application is shutting down. Never hide it.
                raise
            except (ConnectionClosed, OSError, TimeoutError):
                # Network failures are expected operational events; reconnect below.
                LOGGER.exception("Coinbase WebSocket disconnected")

            # Add a small random value to the exponentially increasing retry delay.
            jitter = random.uniform(0, min(1.0, delay * 0.25))
            wait_seconds = delay + jitter
            LOGGER.warning("Reconnecting in %.2f seconds", wait_seconds)
            await asyncio.sleep(wait_seconds)
            # Double the delay after every failure but never exceed the configured cap.
            delay = min(delay * 2, self._reconnect_max_seconds)

    @staticmethod
    def parse_message(message: dict[str, Any]) -> list[ExchangeTrade]:
        """Extract zero or more normalized trades from one Coinbase frame."""

        # Coinbase also sends subscription confirmations and other channel messages.
        if message.get("channel") != "market_trades":
            return []

        # The sequence orders WebSocket messages. It is not the individual trade ID.
        sequence_value = message.get("sequence_num")
        if sequence_value is None:
            # Some provider messages do not expose ordering metadata.
            source_sequence = None
        elif isinstance(sequence_value, int) and not isinstance(sequence_value, bool):
            # JSON booleans are Python integers internally, so reject them explicitly.
            source_sequence = sequence_value
        else:
            raise TypeError("Coinbase sequence_num must be an integer or null")

        # Accumulate all trades found in all events in this frame.
        normalized: list[ExchangeTrade] = []

        # `.get(..., [])` makes a missing optional collection behave as empty.
        for event in message.get("events", []):
            if not isinstance(event, dict):
                raise TypeError("Coinbase event must be a JSON object")

            for trade in event.get("trades", []):
                if not isinstance(trade, dict):
                    raise TypeError("Coinbase trade must be a JSON object")

                # Required keys use `[]`; missing data raises and is logged as malformed.
                source_event_id = str(trade["trade_id"])
                symbol = str(trade["product_id"])
                # Python understands `+00:00`; replace the equivalent JSON `Z` suffix.
                event_time = datetime.fromisoformat(
                    str(trade["time"]).replace("Z", "+00:00")
                )

                # A timestamp without a timezone is ambiguous and must not enter the pipeline.
                if event_time.tzinfo is None:
                    raise ValueError("Exchange timestamp does not contain a timezone")

                # Emit the common boundary type instead of leaking Coinbase-only models.
                normalized.append(
                    ExchangeTrade(
                        exchange="coinbase",
                        symbol=symbol,
                        source_event_id=source_event_id,
                        source_sequence=source_sequence,
                        event_time=event_time,
                        # Copy the dictionary so later source mutations cannot affect it.
                        raw_payload=dict(trade),
                    )
                )

        # The caller yields these objects one at a time.
        return normalized
```

What this code does:

1. Opens a WebSocket connection.
2. Sends a subscription request for the configured symbols.
3. Ignores messages that are not market-trade updates.
4. Converts every source trade into an `ExchangeTrade`.
5. Reconnects after network failures using exponential backoff and random jitter.

Backoff prevents the service from repeatedly hammering an unavailable exchange. Jitter prevents many restarted collectors from reconnecting at exactly the same instant.

Before using real money or treating the data as authoritative, compare the subscription and response fields with the exchange's current official documentation and save real, legally redistributable response fixtures for contract tests.

### File: `/apps/collector/src/crypto_trading_collector/models.py`

Create:

```python
# Canonical JSON encoding makes deterministic ID input unambiguous.
import json
# `UTC` is the single time standard used throughout the pipeline.
from datetime import UTC, datetime
# `Annotated` adds validation rules to a normal string type.
from typing import Annotated, Literal
# UUIDv4 is used for a processing trace; UUIDv5 is used for deterministic event IDs.
from uuid import NAMESPACE_URL, UUID, uuid4, uuid5

# Pydantic validates untrusted values as they enter the application.
from pydantic import (
    AwareDatetime,
    BaseModel,
    ConfigDict,
    Field,
    JsonValue,
    StringConstraints,
    field_validator,
)

# Reuse this definition for fields that must not be blank or whitespace-only.
NonEmptyString = Annotated[
    str,
    StringConstraints(strip_whitespace=True, min_length=1),
]


def utc_now() -> datetime:
    """Return a timezone-aware current timestamp in UTC."""

    return datetime.now(UTC)


def event_id_for_trade(exchange: str, symbol: str, source_event_id: str) -> UUID:
    """Return the same UUID whenever the same source trade is received."""

    # Build identity from source-owned values, never from local receipt time.
    # Normalizing case/whitespace prevents superficial spelling differences from
    # producing different IDs for the same logical source.
    identity = json.dumps(
        [
            # Including event type and version prevents future contract types from colliding.
            "market.trade.raw",
            "v1",
            exchange.strip().lower(),
            symbol.strip().upper(),
            source_event_id.strip(),
        ],
        # Compact separators make the string representation stable and predictable.
        separators=(",", ":"),
    )
    # UUIDv5 hashes the identity into a UUID. Unlike UUIDv4, it is repeatable.
    return uuid5(NAMESPACE_URL, identity)


class MarketTradeRawEvent(BaseModel):
    """Validated Kafka envelope for one raw market trade."""

    model_config = ConfigDict(
        # Reject unknown top-level fields so spelling mistakes fail immediately.
        extra="forbid",
        # Prevent validated event fields from being reassigned later.
        frozen=True,
    )

    # Stable business identity used by downstream deduplication.
    event_id: UUID
    # Literals guarantee that callers cannot label this object as another event type/version.
    event_type: Literal["market.trade.raw"] = "market.trade.raw"
    schema_version: Literal["v1"] = "v1"

    # Source and instrument identify where the trade originated.
    exchange: NonEmptyString
    symbol: NonEmptyString
    # Event time comes from the exchange and drives event-time calculations.
    event_time: AwareDatetime
    # Ingestion time is when this service constructed the envelope.
    ingested_at: AwareDatetime = Field(default_factory=utc_now)

    # Provider trade ID is the source-owned identity used to deduplicate a trade.
    source_event_id: NonEmptyString
    # Message sequence supports ordering/gap analysis; not every provider supplies it.
    source_sequence: int | None = Field(default=None, ge=0)
    # Fixing the producer name makes ownership visible and prevents accidental spoofing.
    producer: Literal["apps.collector"] = "apps.collector"

    # A trace follows this particular processing journey through logs and services.
    trace_id: UUID = Field(default_factory=uuid4)
    # A raw external fact may not yet belong to an internal workflow or cause chain.
    correlation_id: UUID | None = None
    causation_id: UUID | None = None

    # `JsonValue` restricts nested values to data that JSON/Kafka can serialize.
    payload: dict[str, JsonValue]

    # Run the same normalization after Pydantic has parsed both datetime fields.
    @field_validator("event_time", "ingested_at")
    @classmethod
    def normalize_to_utc(cls, value: datetime) -> datetime:
        """Represent every accepted timestamp in UTC."""

        return value.astimezone(UTC)
```

Why these changes matter:

- `event_id` is required instead of randomly generated by the model.
- `event_id_for_trade()` uses UUIDv5, which is deterministic. The same input produces the same UUID.
- `AwareDatetime` rejects timestamps that have no timezone.
- The validator converts valid timezone-aware values to UTC.
- `NonEmptyString` removes surrounding spaces and rejects empty strings.
- `extra="forbid"` catches mistakes such as `eventtime` instead of `event_time`.
- `JsonValue` prevents non-JSON values such as sets or arbitrary Python objects.
- `frozen=True` prevents code from changing an event after validation.
- `trace_id` identifies one processing journey. It may change during replay; `event_id` must not.
- Raw external events have no internal cause, so `correlation_id` and `causation_id` may initially be `None`.

Do not use price, size, or ingestion time as the sole event identity. Those fields may repeat or change representation. Prefer the exchange's immutable trade ID.

## 7. Add validated configuration

### File: `/apps/collector/src/crypto_trading_collector/config.py`

Create:

```python
# `Literal` restricts a setting to known values; `Self` describes the validator result.
from typing import Literal, Self

# Pydantic types parse URLs, protect secret display, and validate field constraints.
from pydantic import AnyUrl, Field, SecretStr, field_validator, model_validator
# BaseSettings maps environment variables into a validated Python object.
from pydantic_settings import BaseSettings, SettingsConfigDict


class CollectorSettings(BaseSettings):
    """Validated environment configuration for the collector process."""

    model_config = SettingsConfigDict(
        # Read local developer values from `.env` when the file exists.
        env_file=".env",
        # `symbols` therefore maps to the environment name `COLLECTOR_SYMBOLS`.
        env_prefix="COLLECTOR_",
        # Ignore unrelated environment variables instead of treating them as errors.
        extra="ignore",
        # Validate defaults too; otherwise a typed default can bypass parsing.
        validate_default=True,
    )

    # Only Coinbase is implemented. Add another Literal when its adapter exists.
    exchange: Literal["coinbase"] = "coinbase"
    # AnyUrl checks that the configured value is a syntactically valid URL.
    websocket_url: AnyUrl = AnyUrl("wss://advanced-trade-ws.coinbase.com")
    # `default_factory` creates a fresh list for each settings object.
    symbols: list[str] = Field(default_factory=lambda: ["BTC-USD"])

    # These local defaults point at Kafka exposed by local Docker infrastructure.
    kafka_bootstrap_servers: str = "localhost:9092"
    kafka_topic: str = "market.trades.raw.v1"
    kafka_client_id: str = "market-data-collector"
    # Local Kafka is plaintext; AWS generally changes only these environment values.
    kafka_security_protocol: Literal["PLAINTEXT", "SSL", "SASL_SSL"] = "PLAINTEXT"
    kafka_sasl_mechanism: Literal[
        "PLAIN",
        "SCRAM-SHA-256",
        "SCRAM-SHA-512",
    ] | None = None
    # SecretStr redacts normal string representations so logs do not expose credentials.
    kafka_sasl_username: SecretStr | None = None
    kafka_sasl_password: SecretStr | None = None

    # `gt=0` and `ge=0` reject invalid retry/timeout values during startup.
    reconnect_initial_seconds: float = Field(default=1.0, gt=0)
    reconnect_max_seconds: float = Field(default=30.0, gt=0)
    kafka_poll_timeout_seconds: float = Field(default=0.1, gt=0)
    kafka_flush_timeout_seconds: float = Field(default=10.0, gt=0)
    kafka_queue_full_retries: int = Field(default=3, ge=0)

    @field_validator("symbols")
    @classmethod
    def validate_symbols(cls, symbols: list[str]) -> list[str]:
        # Normalize values and discard entries containing only whitespace.
        cleaned = [symbol.strip().upper() for symbol in symbols if symbol.strip()]
        if not cleaned:
            raise ValueError("At least one non-empty symbol is required")
        # A dictionary preserves input order while removing duplicates.
        return list(dict.fromkeys(cleaned))

    @field_validator("kafka_bootstrap_servers", "kafka_topic", "kafka_client_id")
    @classmethod
    def validate_non_empty_setting(cls, value: str) -> str:
        # Kafka may fail much later with a confusing error, so reject blanks now.
        cleaned = value.strip()
        if not cleaned:
            raise ValueError("Value must not be empty")
        return cleaned

    @model_validator(mode="after")
    def validate_kafka_authentication(self) -> Self:
        # These three settings form one complete SASL credential group.
        authentication_values = (
            self.kafka_sasl_mechanism,
            self.kafka_sasl_username,
            self.kafka_sasl_password,
        )

        if self.kafka_security_protocol == "SASL_SSL":
            # A partial credential set cannot authenticate and should fail at startup.
            if not all(authentication_values):
                raise ValueError(
                    "SASL_SSL requires a mechanism, username, and password"
                )
        elif any(authentication_values):
            # Credentials with a non-SASL protocol are almost certainly a mistake.
            raise ValueError("SASL credentials require SASL_SSL")

        return self
```

Configuration should come from the environment, not be hard-coded into application behavior. Local development can use a `.env` file. AWS ECS can inject the same settings from task configuration and AWS Secrets Manager.

## 9. Implement the Kafka publisher

### File: `/apps/collector/src/crypto_trading_collector/producer.py`

Create:

```python
# Logging records delivery and backpressure conditions for operators.
import logging
# A deque efficiently stores asynchronous delivery errors in arrival order.
from collections import deque
# Callback describes the delivery-report function accepted by Confluent Kafka.
from collections.abc import Callable
# Any types the provider-owned config mapping; Protocol enables a fake test producer.
from typing import Any, Protocol, cast

# These are the concrete Kafka client, its error types, and delivery message metadata.
from confluent_kafka import KafkaError, KafkaException, Message, Producer

# Settings supply environment-dependent connection values.
from .config import CollectorSettings
# Only already-validated events may enter this publisher.
from .models import MarketTradeRawEvent

LOGGER = logging.getLogger(__name__)


class ProducerLike(Protocol):
    """The small part of Confluent Producer used by this application."""

    def produce(
        self,
        topic: str,
        key: bytes,
        value: bytes,
        headers: list[tuple[str, bytes]],
        on_delivery: Callable[[KafkaError | None, Message], None],
    ) -> None:
        # A Protocol declares method shape; the real and fake producers both match it.
        ...

    def poll(self, timeout: float) -> int:
        # Poll serves queued callbacks and network events.
        ...

    def flush(self, timeout: float) -> int:
        # Flush returns the number of messages still undelivered after the timeout.
        ...


class KafkaEventPublisher:
    """Serialize validated events and enqueue them for Kafka delivery."""

    def __init__(
        self,
        settings: CollectorSettings,
        producer: ProducerLike | None = None,
    ) -> None:
        # Save settings needed for every publish and for bounded shutdown.
        self._topic = settings.kafka_topic
        self._poll_timeout = settings.kafka_poll_timeout_seconds
        self._flush_timeout = settings.kafka_flush_timeout_seconds
        self._queue_full_retries = settings.kafka_queue_full_retries
        # Delivery callbacks run later during poll/flush; keep failures until surfaced.
        self._delivery_errors: deque[KafkaError] = deque()

        # Confluent Kafka uses librdkafka-style dotted configuration names.
        config: dict[str, Any] = {
            "bootstrap.servers": settings.kafka_bootstrap_servers,
            "client.id": settings.kafka_client_id,
            # Broker-level retries from one producer session should not duplicate records.
            "enable.idempotence": True,
            # Wait for all in-sync replicas before acknowledging a write.
            "acks": "all",
            "security.protocol": settings.kafka_security_protocol,
        }

        # Authentication keys must only be added when SASL was configured.
        if settings.kafka_sasl_mechanism is not None:
            username = settings.kafka_sasl_username
            password = settings.kafka_sasl_password
            # Settings validation should make this impossible; the check also narrows types.
            if username is None or password is None:
                raise ValueError("Validated SASL configuration is incomplete")

            config.update(
                {
                    "sasl.mechanism": settings.kafka_sasl_mechanism,
                    # Reveal SecretStr only at the boundary that must send credentials.
                    "sasl.username": username.get_secret_value(),
                    "sasl.password": password.get_secret_value(),
                }
            )

        # Tests inject a fake; production constructs the real C-extension client.
        # The cast bridges incomplete third-party typing with this smaller Protocol.
        self._producer = (
            producer
            if producer is not None
            else cast(ProducerLike, Producer(config))
        )

    def publish(self, event: MarketTradeRawEvent) -> None:
        """Queue an event and surface any earlier asynchronous delivery error."""

        # A zero timeout serves ready callbacks without deliberately waiting.
        self._producer.poll(0)
        self._raise_pending_delivery_error()

        # Stable keys keep one exchange/symbol ordered within a Kafka partition.
        key = f"{event.exchange.lower()}:{event.symbol.upper()}".encode()
        # Pydantic serializes UUIDs, timestamps, and JSON payload values correctly.
        value = event.model_dump_json().encode()
        # Headers expose routing/debug metadata without deserializing the whole value.
        headers = [
            ("event_type", event.event_type.encode()),
            ("schema_version", event.schema_version.encode()),
            ("trace_id", str(event.trace_id).encode()),
        ]

        # Retry only local queue saturation, and only a configured number of times.
        attempts = 0
        while True:
            try:
                self._producer.produce(
                    topic=self._topic,
                    key=key,
                    value=value,
                    headers=headers,
                    on_delivery=self._on_delivery,
                )
                return
            except BufferError:
                if attempts >= self._queue_full_retries:
                    raise

                attempts += 1
                LOGGER.warning(
                    "Kafka producer queue is full; retry %d of %d",
                    attempts,
                    self._queue_full_retries,
                )
                # Polling briefly lets librdkafka drain the local queue.
                self._producer.poll(self._poll_timeout)
                self._raise_pending_delivery_error()

    def close(self) -> None:
        """Wait a bounded amount of time for queued events to be delivered."""

        # Flush invokes callbacks while waiting, so inspect callback errors afterward.
        remaining = self._producer.flush(self._flush_timeout)
        self._raise_pending_delivery_error()

        if remaining:
            raise RuntimeError(
                f"Kafka shutdown timed out with {remaining} undelivered message(s)"
            )

    def _on_delivery(self, error: KafkaError | None, message: Message) -> None:
        # This callback runs only when poll() or flush() serves delivery reports.
        if error is not None:
            self._delivery_errors.append(error)
            LOGGER.error("Kafka delivery failed: %s", error)
            return

        LOGGER.debug(
            "Delivered event to %s partition %s offset %s",
            message.topic(),
            message.partition(),
            message.offset(),
        )

    def _raise_pending_delivery_error(self) -> None:
        # Convert a delayed callback failure into normal synchronous control flow.
        if self._delivery_errors:
            raise KafkaException(self._delivery_errors.popleft())
```

Important concepts:

- Kafka `produce()` queues a message locally; it does not wait for final delivery.
- `poll()` allows Kafka to run delivery callbacks.
- `BufferError` means the local queue is full. A bounded retry avoids either losing immediately or waiting forever.
- `flush()` gives queued messages time to finish during shutdown.
- The Kafka key is stable, so all events for one exchange and symbol are consistently partitioned.
- Kafka idempotence protects certain producer retries. It does not replace the application's stable event ID and downstream deduplication.

The optional `producer` argument is dependency injection. Production uses a real `Producer`; unit tests provide a fake object and do not need a Kafka server.

import asyncio
# Logging gives the process observable lifecycle messages.
import logging

# This is the only currently supported concrete exchange implementation.
from crypto_exchange_adapters.coinbase import CoinbasePublicTradeClient
# ExchangeTrade is the provider-neutral object returned by every adapter.
from crypto_exchange_adapters.models import ExchangeTrade

# Import each local component through its narrow public responsibility.
from .config import CollectorSettings
from .exchange_client import TradeSource
from .models import MarketTradeRawEvent, event_id_for_trade
from .producer import KafkaEventPublisher

LOGGER = logging.getLogger(__name__)


def build_event(trade: ExchangeTrade) -> MarketTradeRawEvent:
    """Convert an exchange-neutral trade into the canonical Kafka event."""

    # Constructing the Pydantic model validates the complete envelope before publish.
    return MarketTradeRawEvent(
        # Build stable identity from the exchange's immutable trade ID.
        event_id=event_id_for_trade(
            exchange=trade.exchange,
            symbol=trade.symbol,
            source_event_id=trade.source_event_id,
        ),
        exchange=trade.exchange,
        symbol=trade.symbol,
        event_time=trade.event_time,
        source_event_id=trade.source_event_id,
        source_sequence=trade.source_sequence,
        # Raw external facts do not yet belong to an internal command chain.
        correlation_id=None,
        causation_id=None,
        # Preserve the parsed provider record inside the validated envelope.
        payload=trade.raw_payload,
    )


def build_trade_source(settings: CollectorSettings) -> TradeSource:
    """Construct the configured exchange adapter."""

    # Keeping selection here prevents the rest of the collector from knowing providers.
    if settings.exchange == "coinbase":
        return CoinbasePublicTradeClient(
            # Pydantic URL objects are converted to the string expected by websockets.
            websocket_url=str(settings.websocket_url),
            symbols=settings.symbols,
            reconnect_initial_seconds=settings.reconnect_initial_seconds,
            reconnect_max_seconds=settings.reconnect_max_seconds,
        )

    # This is defensive today because Literal already allows only Coinbase.
    raise ValueError(f"Unsupported exchange: {settings.exchange}")


async def run(settings: CollectorSettings) -> None:
    """Run until cancelled or a fatal publication error occurs."""

    source = build_trade_source(settings)
    # Construction opens no network connection but prepares the Kafka client.
    publisher = KafkaEventPublisher(settings)

    try:
        # Wait for trades one at a time without blocking the process while idle.
        async for trade in source.trades():
            publisher.publish(build_event(trade))
    except asyncio.CancelledError:
        LOGGER.info("Collector shutdown requested")
        # Re-raising lets asyncio complete its normal cancellation protocol.
        raise
    finally:
        # Always attempt bounded delivery of already queued messages.
        publisher.close()


def main() -> None:
    """Load settings and start the asynchronous application."""

    # Configure a readable default format before any component writes logs.
    logging.basicConfig(
        level=logging.INFO,
        format="%(asctime)s %(levelname)s %(name)s %(message)s",
    )

    # Environment errors fail fast before WebSocket or Kafka work begins.
    settings = CollectorSettings()

    try:
        # asyncio.run creates, runs, and closes the event loop.
        asyncio.run(run(settings))
    except KeyboardInterrupt:
        # Ctrl+C is an expected operator action rather than an error traceback.
        LOGGER.info("Collector stopped")


if __name__ == "__main__":
    # This also permits `python -m crypto_trading_collector.main` during debugging.
    main()
```

`main.py` is intentionally small. It connects existing components but does not contain exchange parsing, Kafka internals, or validation rules. Small entry points are easier to understand and test.

from crypto_trading_collector.models import MarketTradeRawEvent, event_id_for_trade
from crypto_trading_collector.producer import KafkaEventPublisher


class FakeProducer:
    """Record Kafka calls in memory without opening a broker connection."""

    def __init__(self) -> None:
        self.messages: list[dict[str, Any]] = []
        # Tests can change this to simulate messages left after flush timeout.
        self.flush_result = 0

    def produce(
        self,
        topic: str,
        key: bytes,
        value: bytes,
        headers: list[tuple[str, bytes]],
        on_delivery: Callable[..., None],
    ) -> None:
        # Store exactly what the application attempted to publish.
        self.messages.append(
            {
                "topic": topic,
                "key": key,
                "value": value,
                "headers": headers,
                "on_delivery": on_delivery,
            }
        )

    def poll(self, timeout: float) -> int:
        # No background network events exist in this in-memory fake.
        return 0

    def flush(self, timeout: float) -> int:
        # Match Confluent's contract: return how many messages remain.
        return self.flush_result


def build_event() -> MarketTradeRawEvent:
    # Centralize valid setup so publisher tests focus on publisher behavior.
    return MarketTradeRawEvent(
        event_id=event_id_for_trade("coinbase", "BTC-USD", "123"),
        exchange="coinbase",
        symbol="BTC-USD",
        event_time="2026-08-11T15:30:00Z",
        source_event_id="123",
        source_sequence=42,
        correlation_id=None,
        causation_id=None,
        payload={"trade_id": "123"},
    )


def test_uses_stable_exchange_and_symbol_key() -> None:
    settings = CollectorSettings()
    fake = FakeProducer()
    # Dependency injection ensures construction does not contact Kafka.
    publisher = KafkaEventPublisher(settings, producer=fake)

    publisher.publish(build_event())

    # Topic and key are part of the collector-to-Kafka contract.
    assert fake.messages[0]["topic"] == "market.trades.raw.v1"
    assert fake.messages[0]["key"] == b"coinbase:BTC-USD"


def test_shutdown_reports_undelivered_messages() -> None:
    settings = CollectorSettings()
    fake = FakeProducer()
    # Pretend one queued message was still not delivered when the timeout ended.
    fake.flush_result = 1
    publisher = KafkaEventPublisher(settings, producer=fake)

    # Silently exiting here could lose data, so close must report the problem.
    with pytest.raises(RuntimeError, match="1 undelivered"):
        publisher.close()
```

The fake producer records calls in memory. This proves the collector's behavior without installing or starting Kafka.

## 13. Add a schema contract test

### File: `/tests/contract/test_market_trade_raw_v1.py`

Create:

```python
# JSON loads both the schema definition and representative event fixture.
import json
# Path creates operating-system-independent repository paths.
from pathlib import Path

# Draft202012Validator applies the selected schema dialect; FormatChecker checks UUID/time.
from jsonschema import Draft202012Validator, FormatChecker

# This test lives at tests/contract/file.py, so two parents reach repository root.
REPOSITORY_ROOT = Path(__file__).resolve().parents[2]
CONTRACT_DIRECTORY = (
    REPOSITORY_ROOT / "schemas" / "events" / "market.trade.raw.v1"
)


def validator() -> Draft202012Validator:
    # Load once per call so no test can mutate shared schema state.
    schema = json.loads(
        (CONTRACT_DIRECTORY / "schema.json").read_text(encoding="utf-8")
    )
    return Draft202012Validator(schema, format_checker=FormatChecker())


def valid_fixture() -> dict[str, object]:
    # Return a fresh dictionary because rejection tests intentionally mutate it.
    return json.loads(
        (CONTRACT_DIRECTORY / "valid-example.json").read_text(encoding="utf-8")
    )


def test_valid_fixture_matches_json_schema() -> None:
    # Sorting makes a potential failure list deterministic and readable.
    errors = sorted(
        validator().iter_errors(valid_fixture()),
        key=lambda error: error.json_path,
    )

    assert errors == []


def test_schema_rejects_unknown_envelope_field() -> None:
    fixture = valid_fixture()
    # additionalProperties=false should reject accidental envelope expansion.
    fixture["unexpected"] = "mistake"


    assert list(validator().iter_errors(fixture))


def test_schema_rejects_naive_timestamp() -> None:
    fixture = valid_fixture()
    # This timestamp has no Z suffix or UTC offset and is therefore ambiguous.
    fixture["event_time"] = "2026-08-11T15:30:00"

    assert list(validator().iter_errors(fixture))
```

Unit tests validate Python behavior. Contract tests validate the shared event definition. You need both because a Pydantic model could work while accidentally disagreeing with Spark or another consumer.

## 14. Install and run it locally

From the repository root, the preferred reproducible workflow is:

```powershell
# Create a project-local Python environment if it does not already exist.
python -m venv .venv
# Activate it so subsequent commands use the project's Python and scripts.
.\.venv\Scripts\Activate.ps1
# Install uv inside the project environment rather than globally.
python -m pip install "uv>=0.8,<1"
# Resolve every workspace dependency and record exact versions in uv.lock.
uv lock
# Install the collector, local adapter, and optional development tools.
uv sync --package crypto-trading-collector --extra dev
# Create a private local settings file from the safe example.
Copy-Item .env.example .env
# Run unit and contract tests before starting a long-lived service.
uv run --package crypto-trading-collector pytest
# Start the collector; this requires reachable Kafka and Internet access.
uv run --package crypto-trading-collector crypto-collector
```

Before starting the collector, local Kafka must be running and `localhost:9092` must be reachable. The topic `market.trades.raw.v1` must either exist or your local Kafka configuration must allow topic auto-creation.

If you use `pip` instead of `uv`:

```powershell
# Create and activate an isolated environment.
python -m venv .venv
.\.venv\Scripts\Activate.ps1
# Install the reusable adapter as editable so source changes take effect immediately.
python -m pip install -e .\packages\exchange_adapters
# Install the collector plus its `dev` dependency group as editable.
python -m pip install -e ".\apps\collector[dev]"
# Verify behavior, then start the registered console command.
pytest
crypto-collector
```

Never commit `.venv/`, `.env`, credentials, or local Kafka data.

## 15. What remains after this walking skeleton

The code above is a working, tested collector skeleton, not the finished platform.
Add these next, in this order:

1. Add counters for received, published, malformed, delivery-failed, reconnect, and source-gap events.
2. Add health and readiness endpoints.
3. Add an integration test using disposable Kafka through Testcontainers or Docker Compose.
4. Add a dead-letter path for malformed messages with bounded error details.
5. Detect source sequence gaps where the selected exchange provides meaningful ordering.
6. Containerize the exact same command used locally.
7. Configure AWS MSK networking, TLS/SASL, IAM or SCRAM secrets, and observability through infrastructure—not hard-coded application branches.

Do not add Spark candle processing to the collector. The collector publishes raw trades; a separate streaming job reads them and creates candles.

## 16. Recommended implementation order

Follow this order so each step can be tested before more complexity is introduced:

```text
1. Package layout and dependency installation
2. Canonical JSON Schema and fixture
3. Strict Pydantic event model
4. Deterministic event identity tests
5. ExchangeTrade boundary model
6. Recorded Coinbase message normalization tests
7. Kafka publisher and fake-producer tests
8. Thin main process
9. Local Kafka integration test
10. Metrics, health checks, and container image
11. AWS deployment configuration
```

If a step does not pass its tests, fix it before moving to the next step. That keeps failures small and understandable.
